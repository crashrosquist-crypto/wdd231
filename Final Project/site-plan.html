AnimeHut Site Plan

By Crash Rosquist

1. Site Name

AnimeHut

Reasoning: A short catchy name that users can remember. Sort of a gathering place for fans alike to look at the latest info.

2. Site Purpose

The purpose of AnimeHut is to have a place where users can find trending and popular animes. Using external API to find what is trending.

3. Scenarios

  • "I want to find a specific anime movie I heard about, but I only know part of the title. How can I find the full details and see its rating?"
  • "I’m looking for something currently airing. Can I filter my search to only show series that haven't finished yet?"

4. Color Scheme

Primary: #2C3E50
Secondary: #E74C3C
Accent: #ECF0F1

The primary blue will be used for headers and navigation. The secondary red will be used for buttons and badges (like ratings). The off-white will be used for page backgrounds.

5. Typography

Headings: Montserrat (Sans-serif) - Bold and modern.

Body Text: Open Sans (Sans-serif) - Clean and easy to read.
